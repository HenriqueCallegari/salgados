# 🍟 Royal Salgados

Sistema web moderno para divulgação e pedidos de salgados, desenvolvido com foco em performance, experiência visual e conversão de clientes.

## 🚀 Sobre o Projeto

O **Royal Salgados** é uma landing page/site de apresentação para uma marca de salgados, criada para oferecer:

* Visual moderno e profissional
* Navegação simples e responsiva
* Exibição de produtos e combos
* Integração com WhatsApp
* Experiência otimizada para dispositivos móveis
* Estrutura pronta para expansão futura

O objetivo do projeto é unir design atrativo com uma experiência rápida e prática para aumentar pedidos e fortalecer a identidade da marca.
